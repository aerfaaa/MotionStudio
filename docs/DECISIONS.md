# Decisions

Short records of choices that are hard to change later.

1. **Time is whole ticks, 141,120,000 per second.** Divisible by all common frame rates (including 1001-based ones) and audio sample rates. Chosen after testing 600,000, which missed 72, 90 and 144 fps and 44.1/48 kHz audio.
2. **Frame rates are exact fractions, frame times come from frame numbers.** No accumulation, no drift.
3. **Compositions store pixels; screens are handled by `Viewport` only.**
4. **MotionCore has no Apple-only imports.** It stays testable on Linux and can never depend on UI.
5. **Everything is a value type.** Copies are snapshots, which makes undo trivial and rendering safe to run off the main thread later.
6. **Every edit is a Command.** Undo, redo, saving and future scripting share one path.
7. **Undo stores whole-project snapshots.** Simple and reliable. Revisit if projects get large.
8. **The renderer contract is `ResolvedFrame`.** The preview, a future Metal renderer and the exporter all consume it. I did not add a renderer protocol in V1 because without a second renderer it would be a guess.
9. **Project = folder with `project.json` and `media/`.** Media never goes inside the JSON.
10. **`schemaVersion` from day one.** Newer files are refused. Later fields use optional decoding.
11. **Effects are data, not code.** An effect is an ID plus animatable parameters, so presets and a future effect graph need no executable plugins.
12. **The model supports several compositions and parent layers now**, even though the interface uses one composition and no parents. Commands carry a composition ID.
13. **Layer order: index 0 is the top**, as in After Effects. The evaluator returns bottom-first drawing order.
14. **Xcode project generated by XcodeGen** because you have no Mac.
15. **iOS 17 minimum** for the Observation framework. Revisit if you need older devices.
16. **MIT license.** Permissive and App Store friendly. This is not legal advice; check dependencies when any are added (V1 has none).
17. **Placeholder identity:** name "Motion Studio", bundle ID `com.example.motionstudio`. Change before any public release.
18. **Keyframe edits are commands** (`MoveKeyframe`, `SetKeyframeInterpolation`, `InsertKeyframe`), so undo, saving and drags work like every other edit. A drag is one undo step.
19. **Keyframes are selected and dragged in the timeline lanes with one gesture per lane**, not one per diamond, because a diamond is recreated when its time changes and would lose the drag.
20. **Easing is one cubic Bezier per segment.** Independent in and out handles, and spatial paths, need a model change and are deferred.
21. **The effect catalogue is generated from the specification's list** and an independent test holds a second copy. Every effect is `missing` until it renders, and a test enforces that.
22. **Liquid Glass is deferred.** It cannot be verified without a compiler and could break the only build we have.
23. **Theme colours are dynamic** so light and dark share one set of names.
24. **The timeline size is stored as a fraction of the screen height** so it adapts across devices.
25. **Effects are plain Swift on a float pixel array (`PixelImage`)**, not Core Image. Reason: exact, deterministic tests with known pixel values, identical behaviour everywhere, and no unverifiable filter details without a Mac. Cost: CPU speed, mitigated by a reduced-size preview copy and background processing. A GPU path can replace it behind `EffectPipeline` later.
26. **Effect settings are written in layer pixels** and scaled by the preview's bitmap-pixels-per-layer-pixel, so previews and full-size results agree and results do not depend on the composition size.
27. **Effects run on image layers only for now.** Shapes would need rasterising first. The panel and the `AddEffect` command both refuse other layer types.
28. **Media is copied into `media/` inside the project** and referenced by a relative `media/<file>` path. Anything else is refused, so a damaged project cannot point outside its folder.
29. **No project format version bump.** `Asset.pixelSize` is optional and old files decode unchanged (tested).
30. **Unknown effects are kept in the file and skipped when drawing**, never deleted, so a project from a newer version is not damaged by opening it.
31. **The preview keeps showing the previous effect result until the new one is ready** (no flicker, no fake overlay).
32. **Statuses are computed:** an effect is Partial exactly when processing code is connected. Nothing is Working until its tests have run and passed.
